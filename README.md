# TactileAI - بصيرة وسمع لمسي 📳🤖

تطبيق ويب تقدمي (PWA) وتطبيق أندرويد تفاعلي مصمم خصيصاً لخدمة فئة **المكفوفين والصم (Deaf-Blind)** للتعامل مع الأسئلة والاختبارات عبر محرك **Gemini Live Flash** وترجمة الإجابات فورياً إلى **أنماط اهتزازات لمسية (Haptic Vibrations)**.

---

## 🌟 مميزات النظام
- **زر تحكم مركزي ضخم**: زر واحد سهل اللمس في منتصف الشاشة لبدء وإيقاف الاستماع.
- **محرك صوتي متعدد النماذج**: يدعم نموذج `gemini-2.5-flash-native-audio-latest` ونماذج Gemini 2.0 Flash السريعة.
- **قاموس الهزازات اللمسي (Haptic Protocol)**:
  - `1` (أ): هزة واحدة واضحة (`350ms`).
  - `2` (ب): هزتان متتاليتان (`300ms + 300ms`).
  - `3` (ج): 3 هزات متتالية.
  - `4` (د): 4 هزات متتالية.
  - `T` (صح): هزة واحدة طويلة وممتدة (`700ms`).
  - `F` (خطأ): هزتان طويلتان (`450ms + 450ms`).
  - `0` (غير واضح / أعد السؤال): نبضات سريعة متتالية لتنبيه المستخدم بالإعادة.
- **محاكي صوتي ومرئي**: لتجربة واختبار الهزات على الأجهزة التي لا تدعم الهزاز الفيزيائي (مثل أجهزة الكمبيوتر المكتبية).
- **إبقاء الشاشة نشطة (Screen WakeLock)**: لمنع قفل الهاتف وتوقف المايكروفون أثناء جلسة الاستماع.
- **قاموس اختبار الهزات**: لوحة مدمجة تتيح للمستخدم أو المساعد تجربة واختبار كل هزة على حدة.

## 🚀 التشغيل السريع (Local Development)

1. **تثبيت الحزم (Dependencies)**:
   ```bash
   npm install
   ```

2. **تشغيل السيرفر المحلي**:
   ```bash
   npm run dev
   ```

3. افتح المتصفح على: `http://localhost:3000`

---

## 📱 طريقة النقل والتشغيل على الموبايل

### 1. الرفع على Vercel كـ PWA (الأسهل والأسرع - موصى به) ⭐
1. قم برفع مجلد المشروع إلى حسابك على GitHub.
2. ادخل على [Vercel.com](https://vercel.com) واعمل Import للمشروع واضغط **Deploy**.
3. أضف متغيرات البيئة في إعدادات Vercel:
   - `GEMINI_API_KEY`: مفتاحك الخاص.
   - `GEMINI_MODEL`: `gemini-2.5-flash-native-audio-latest`
4. افتح الرابط من متصفح **Google Chrome** على الموبايل، ثم اضغط على القائمة واختر **"إضافة إلى الشاشة الرئيسية" (Install App / Add to Home Screen)**.
5. سيعمل التطبيق فوراً كبرنامج مستقل بملء الشاشة مع دعم كامل للمايكروفون ونظام الهزاز الحقيقي.

---

### 2. التحويل لملف تطبيق أندرويد APK (عبر Capacitor) 📦
المشروع مجهز بالفعل بملف `capacitor.config.json`. لتحويله لملف `.apk`:
```bash
npm run build
npx cap add android
npx cap copy
npx cap open android
```
ثم من برنامج Android Studio اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)** لتحصل على ملف `.apk` تثبته على أي هاتف مباشرة بدون إنترنت استضافة.
